# Scanner Tênis & Tênis de Mesa

Aplicação Streamlit para listar partidas reais e gerar uma análise estatística simples usando dados públicos.

## Deploy no Streamlit Community Cloud
1. Crie um repositório no GitHub.
2. Envie `app.py` e `requirements.txt`.
3. Crie um app apontando para `app.py`.

## Importante
A integração atual usa endpoints públicos não documentados/oficiais do ecossistema Sofascore. A própria Sofascore informa que não fornece seus dados como API pública oficial. Se o endpoint mudar ou bloquear o acesso, será necessário trocar o provedor.

As probabilidades são estimativas estatísticas e não representam garantia de acerto ou lucro.
